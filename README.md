# MartoLevelPlayAdapter

Unity LevelPlay (IronSource) mediation custom adapter for MartoSDK.

## Requirements

- iOS 13.0+
- [MartoSDK](https://github.com/martosdk/MartoSDK-iOS) 1.11.0
- IronSourceSDK

## Usage

Add the source files in `MartoLevelPlayAdapter/` to your project together with MartoSDK and the LevelPlay SDK.
